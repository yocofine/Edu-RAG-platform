# 上传文件编码与预览修复

文本类上传现在统一按 `UTF-8 BOM → UTF-8 → GB18030 → GBK` 解码，解析结果以 UTF-8 保存，避免 Windows 记事本、Excel 导出的中文文件出现乱码。CSV/TSV 使用相同策略。

容器预览环境增加 Noto CJK 中文字体，LibreOffice 生成的 Office 预览 PDF 可正确显示中文。解析质量报告会记录替换字符、控制字符和可疑乱码比例；质量不合格的内容应进入复核，不应建立索引。

修复代码部署后，已经上传的乱码版本不会自动改变，请在文件管理中对这些文件执行“重新解析/重新上传”，待状态变为“已发布”后再检索。
